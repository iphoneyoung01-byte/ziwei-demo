# 紫微斗数命盘 Demo

这是一个基于 React + TypeScript 的紫微斗数命盘演示页面，用于展示“出生信息 → 命盘生成 → 12 宫结构 → 关键词解读”这一流程。

## 介绍

这个项目适合做展示型 demo，重点在于交互体验、命盘结果呈现和整体视觉表达。它不是专业占星系统，也不声称具备高精度的天文排盘能力。

## 运行方式

```bash
npm install
npm run dev
```

然后访问浏览器中的本地地址，例如：

```bash
http://localhost:5173
```

## 构建

```bash
npm run build
```

## 结构概览

- `src/App.tsx`：页面主框架与交互
- `src/lib/ziwei.ts`：命盘生成逻辑
- `src/index.css`：视觉样式与布局

## 说明

- 本项目用于演示与展示，不适合作为严肃占星、命理咨询或医疗心理判断依据。
